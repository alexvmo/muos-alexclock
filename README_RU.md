# AlexClock для MustardOS (muOS)

Минималистичное приложение с часами, датой, индикатором заряда батареи, регулировкой яркости экрана и прогнозом погоды для портативных ретро-консолей под управлением **MustardOS (muOS)**.

## Возможности
- **Крупные часы с секундами** и отображением текущей даты и дня недели.
- **Прогноз погоды в реальном времени:** автоматически определяет город и показывает температуру, состояние неба, скорость ветра (м/с) и влажность (%).
- **Работа без сторонних библиотек:** написано на чистом Python 3 с использованием системных библиотек `SDL2` и `SDL2_ttf` из прошивки muOS.
- **Офлайн-кэш:** сохраняет координаты, последние данные о погоде и выбранный язык в файле `config.json`.
- **Двуязычный интерфейс:** мгновенное переключение между английским (по умолчанию) и русским языками.

## Управление

| Кнопка | Действие |
| :--- | :--- |
| **Вверх / Вниз (D-Pad)** | Изменить яркость экрана (шаг 10%) |
| **Влево / Вправо (D-Pad) или L1 / R1** | Переключить язык (`EN` / `RU`) |
| **MENU + START** | Выйти из приложения |

## Установка
1. Скачайте готовый архив **`AlexClock.muxapp`** из раздела [Releases](../../releases).
2. Скопируйте файл `AlexClock.muxapp` на SD-карту в папку **`ARCHIVE/`**.
3. На консоли откройте **Applications → Archive Manager**.
4. Выберите `AlexClock.muxapp` и нажмите **A** для установки.

## Ручная настройка города
Если консоль используется без подключения к интернету или нужно зафиксировать конкретный город, отредактируйте файл `MUOS/application/AlexClock/config.json`:

```json
{
  "lang": "ru",
  "city_ru": "Москва, RU",
  "city_en": "Moscow, RU",
  "lat": 55.7558,
  "lon": 37.6173
}
```
